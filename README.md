# HWPX → TXT + EPUB

macOS용 통합 전자책 변환기입니다.

출력 형식은 두 가지입니다.

- **단행본형:** 표지 → 목차 페이지 → 여러 장 → 판권
- **연재형:** 표지 → `작품명 + 화수` → 판권. 별도 목차 페이지는 만들지 않습니다. 첫 번째 비어 있지 않은 줄 전체를 기능 목차 인덱스로 사용하고, 두 번째 비어 있지 않은 줄은 본문 상단의 작은 부제목으로 표시합니다.

연재형 제목과 부제목은 색상·테두리·장식 없이 글자 크기와 굵기만으로 구분합니다. 출력 파일명은 첫 줄의 `작품명 + 화수`를 사용합니다. 같은 이름의 결과가 있으면 앱이 기존 파일을 대치할지 확인합니다.

단행본형 출력 파일명도 원본 HWPX 파일명이 아니라 원고의 첫 번째 비어 있지 않은 줄인 `작품명 + n권`을 사용합니다.

1. HWPX 원고를 선택합니다.
2. PNG/JPG/WEBP 표지를 선택합니다.
3. 필요하면 출력 폴더를 선택합니다. 기본값은 HWPX 원본 폴더입니다.
4. 판권을 직접 등록하려면 제목, 지은이, 발행처, 발행일, UCI, 투고문의, 저작권 문구를 입력합니다.
5. **TXT + EPUB 만들기**를 누릅니다.

결과로 같은 이름의 `.txt`와 `.epub` 파일이 생성됩니다. EPUB은 TXT의 목차와 판권을 자동 인식하고 `표지 → 목차 → 각 장 → 판권` 순서로 구성합니다.

## 유통 플랫폼 프리셋

- **카카오페이지:** EPUB 2.0, `cover.xhtml`, `copyright.xhtml`, 모든 연재 회차에 표지와 판권 포함, 표지를 sRGB JPEG 가로 1080px·500KB 이하로 최적화, XHTML 300KB 및 이미지 500KB 제한 검사
- **리디북스:** EPUB 2.0, `cover.html`, `copyright.html`, 연재 2화부터 대표 표지 이미지·메타데이터는 유지하면서 읽기 순서의 표지 페이지와 판권만 제외, 표지를 sRGB JPEG 가로 1120px로 최적화, EPUB 전체 1MB 제한 검사

두 프리셋 모두 본문 글자 크기 `1em`, 줄간격 `1.8em`, 여백 `0em`을 사용하며 CSS 길이 단위는 `em`과 `%`만 사용합니다. 본문의 한 줄 전체가 `* * *`이면 장면 전환 구분자로 인식해 가운데 정렬합니다. 연재 회차는 첫 번째 비어 있지 않은 줄의 `1화`, `01화`, `001화`, `제1화` 형식을 인식합니다. 회차를 인식하지 못하면 안전을 위해 표지와 판권을 포함합니다.

## 폴더 일괄 처리

입력 방식에서 **폴더 일괄 처리**를 선택한 뒤 단행본형 또는 연재형을 고르면, 선택한 폴더 바로 아래의 모든 `.hwpx` 원고를 파일명 순서로 변환합니다. 한 장의 공통 표지와 현재 입력된 공통 판권정보가 모든 파일에 적용됩니다.

- 단행본형: 첫 번째 비어 있지 않은 줄의 `작품명 + n권`으로 TXT와 EPUB 파일명 생성
- 연재형: 첫 번째 비어 있지 않은 줄의 `작품명 + 화수`로 TXT와 EPUB 파일명 생성

- 기존 파일 모두 대치: 같은 이름의 TXT와 EPUB을 새 결과로 교체
- 기존 파일 건너뛰기: 이미 결과가 있는 회차는 변환하지 않음

하위 폴더는 검색하지 않습니다. 결과 폴더를 별도로 고르지 않으면 선택한 원고 폴더에 저장합니다.

판권 입력란을 사용하면 기존 판권 블록을 교체하며, 원고에 판권이 없으면 자동으로 마지막에 추가합니다. 입력란을 모두 비워두면 원고의 판권 내용을 그대로 사용합니다.

단행본형과 연재형 모두 판권 페이지의 각 항목 사이에 한 줄의 빈 줄을 넣어 동일한 간격으로 표시합니다.

**판권정보 저장하기**를 누르면 현재 입력값이 macOS 사용자 설정에 저장되고, 앱을 종료했다가 다시 실행해도 자동으로 복원됩니다. 빈 값으로 저장하면 기존 저장값도 비워집니다.

판권 입력란에서는 macOS 표준 단축키인 `⌘X`, `⌘C`, `⌘V`, `⌘A`, `⌘Z`를 사용할 수 있습니다.

## 다른 Mac에서 사용

현재 빌드는 Apple Silicon(M1 이상)용입니다. 앱이 Apple Developer ID로 공증되지 않았으므로, 처음 실행할 때 Finder에서 앱을 우클릭한 뒤 **열기**를 선택해야 할 수 있습니다.
